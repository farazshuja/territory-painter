# Territory Painter

A neon ink, two-player arcade battle. Splash across the arena, collect power-ups, and claim more territory than your rival.

## Play

**Live game:** https://farazshuja.github.io/territory-painter/

- Player 1 moves with **W A S D**; Player 2 uses the **arrow keys**.
- Xbox controllers can move with the left stick or D-pad. Press **Menu** for settings and **View** to restart.
- Paint unclaimed tiles for 10 points. Rival ink blocks movement unless you have a Golden Apple.
- Junk food slows you down; fresh food, shoes, and a skateboard boost speed. The snowflake freezes your rival.
- Press **R** to restart or **M** to toggle sound.

The original mascots are small squid-like ink characters. Freshly painted splats shine, then settle into matte neon ink.

## Development

Open `index.html` in a modern browser. The game uses a responsive HTML canvas and has no build step.

GitHub Pages deploys the root site from the `master` branch using `.github/workflows/pages.yml`.
